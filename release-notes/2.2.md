# SphereDex 2.2 release notes (draft)

Not a store listing. The app version and the Play and App Store text stay on the current release until this draft is reviewed.

## Printable checklist

From Missing Cards, for the goal you have selected, and from a set, save an A4 or Letter PDF. Each line is the card number, the name, the rarity and a tick box. Choose missing cards only, or include the cards you already own in grey. The list uses the same completion check as the progress bars, and it is created on the device, so it works offline.

## English and Japanese progress

Ownership can record English or Japanese separately from 1st and 2nd edition. Cards you already own stay English. Leave Japanese collection off in Settings and the app behaves as it does today. Turn it on and PalDex, Missing Cards, set completion and Set Spheres can show English, Japanese or both. Adding and scanning ask which language you are holding. The spreadsheet gains a Language column. An older spreadsheet, with no Language column, still imports, and those cards stay English.

## Second marketplace price (not in this draft)

A labelled price from another venue, shown next to the eBay last-sold figure, is not included. Vendor Tools’ terms of use, section 9, effective 6 August 2026, restrict the API to non-competing products and say not to use it to operate a competing catalogue, pricing feed or public market-data product. They also ask anyone building an overlapping tool to contact support@vendortools.net before building or shipping. SphereDex is a public collection app with an eBay price layer, so this draft does not call `https://api.vendortools.net`, does not embed a key, and maps no printings to Vendor Tools card ids. With no key configured, prices stay exactly the eBay live and last-sold figures the app already shows.
