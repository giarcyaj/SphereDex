# SphereDex 2.2 release notes (draft)

Not a store listing. The app version and the Play and App Store text stay on the current release until this draft is reviewed.

## Printable checklist

From Missing Cards, for the goal you have selected, and from a set, save an A4 or Letter PDF. Each line is the card number, the name, the rarity and a tick box. Choose missing cards only, or include the cards you already own in grey. The list uses the same completion check as the progress bars, and it is created on the device, so it works offline.

## English and Japanese progress

Ownership can record English or Japanese separately from 1st and 2nd edition. Cards you already own stay English. Leave Japanese collection off in Settings and the app behaves as it does today. Turn it on and PalDex, Missing Cards, set completion and Set Spheres can show English, Japanese or both. Adding and scanning ask which language you are holding. The spreadsheet gains a Language column next to the Paid column from 2.1. A spreadsheet from 2.1, or from before Paid and Language existed, still imports. Cards with no Language column stay English, and a missing Paid cell stays unrecorded.
